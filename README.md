## 🚀 What I'm Building

### 🧰 Raspberry Pi Cyberdeck

A compact, portable computing and experimentation setup built around a
**Raspberry Pi 3B+**.

-   Lightweight Linux desktop and performance tuning.
-   Offline knowledge access with **Kiwix**.
-   Networking and packet-analysis experiments using tools such as
    **Scapy**.
-   A multi-display interface with a main screen and small OLED status
    displays.
-   Hardware integration and telemetry experiments.

**Status:** Iterative build and software integration.

### 📡 ESP32-S3 Edge Node

Experimenting with an **ESP32-S3** as a companion microcontroller for
the cyberdeck.

-   USB-connected communication with the Raspberry Pi.
-   Wi-Fi connectivity and sensing experiments.
-   Exploring how lightweight edge processing can complement a
    Linux-based main system.
-   Planning telemetry for connection status and small displays.

**Status:** Prototyping and integration.

### 🎮 Game Development Journey

Working toward making games while learning the fundamentals instead of
